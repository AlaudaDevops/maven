# Alauda Derivative Distribution Notice

This repository contains a derivative distribution line maintained by Alauda.

## Scope

- Branch naming for derivative maintenance: `alauda-vX.Y.Z`.
- Tag naming for derivative releases: `vX.Y.Z-alauda-N`.
- Example:
  - Branch: `alauda-v3.9.14`
  - Tag: `v3.9.14-alauda-1`

## Upstream Attribution

- Upstream project: Apache Maven.
- Upstream source repository: https://github.com/apache/maven
- A derivative release in this fork is based on the corresponding upstream baseline and additional downstream changes.

## Release Metadata

Every derivative release should include:

- The upstream baseline version.
- The derivative branch used to build the artifacts.
- The exact release commit SHA.
- A clear statement that the release is maintained by Alauda.
